# v0.1.1 验证范围 / Validation scope

以下汇总 2026-10-16 发布准备期间已完成的检查，区分自动测试、设备实测和未验收事项。工具环境为 Xcode 26.3 / Swift 6.2.4；部署目标为 macOS 14 / iOS 17。构建通过不代表所有操作系统版本和设备组合均已验收。

This document summarizes checks completed during release preparation on October 16, 2026, distinguishing automated tests, device testing, and unverified behavior. The toolchain was Xcode 26.3 / Swift 6.2.4, targeting macOS 14 / iOS 17. A successful build does not validate every supported operating system and device combination.

## v0.1.1 编辑高度修复 / v0.1.1 editor height fix

Mac 与 iPhone 构建通过。AppKit 原生布局及真实 SwiftUI 原位编辑结构检查覆盖长文增高、删除回缩、宽度改变后的重新换行、末尾换行符、64 点额外书写空间和仅保留主页面滚动。UIKit 模拟器检查覆盖真实绑定驱动的增高与回缩、窄宽布局、末尾留白以及禁用输入区内部滚动。

Mac and iPhone builds passed. Native AppKit layout and the production SwiftUI inline editor checks cover long-content growth, shrinkage after deletion, wrapping after width changes, trailing newlines, 64 points of extra writing space, and a single main-page scroller. UIKit simulator checks cover real binding-driven growth and shrinkage, narrow and wide layouts, blank writing space, and disabled inner scrolling.

Mac 隔离演示数据实测了 18 条长文粘贴、Markdown 与公式实时预览、缩短后回缩、撤销恢复长文及快捷键保存；正式记录仅打开编辑器核对后取消，保存字段与更新前一致。未据此声称已覆盖真实 iPhone 的所有输入法、键盘或手势组合。

Isolated Mac demo data verified pasting 18 long items, live Markdown and formula previews, shrinking after shortening the text, undoing to restore the long text, and keyboard-shortcut saving. Real entries were only opened for inspection and canceled, and their saved fields matched the pre-update data. These checks do not establish coverage of every input method, keyboard, or gesture combination on a physical iPhone.

Mac 与真实 iPhone 修复版均已覆盖安装并成功启动，更新前后各自的全部保存字段、关联和引用快照一致。两端签名完整性检查通过。

The fixed builds were installed over the existing Mac and physical iPhone apps and launched successfully. Each device retained every saved field, relationship, and reference snapshot from before its update. Signature integrity checks passed on both builds.

使用最终 macOS 发行二进制，仅更换检查副本的应用标识以创建从未存在的本地沙盒，不使用 UI 测试启动参数、不绑定同步账号。实际界面和一致性数据库副本均核对为 3 个通用示例项目、6 条示例记录，引用为空；检查未读取或修改正式应用数据库。固定示例清单测试另行核对项目名、标题及关联。发行包不包含此检查生成的数据库。

Both the actual UI and a consistent database copy contained three generic sample projects and six sample entries, with no references. The check did not read or modify the production app database. A separate fixed sample-allowlist test verified names, titles, and relationships. The database generated by this check is not included in the release.

本次发布重新运行的 10 组回归检查全部通过，涵盖同步、预加载、Markdown、持久化、清单、日期、引用、保存失败、编辑布局及示例内容；macOS Release 通用构建与 iOS Release 模拟器源码构建通过。固定版本依赖扫描为 0 项已知漏洞。已发布 v0.1.0 的 GitHub 实际附件及完整历史也重新通过隐私与密钥扫描。

All ten regression groups rerun for this release passed: sync, preload, Markdown, persistence, checklists, dates, references, save failure, editor layout, and sample content. The universal macOS Release build and iOS Release simulator source build passed. The pinned dependency audit reported zero known vulnerabilities. The actual GitHub v0.1.0 assets and complete history also passed renewed privacy and secret scans.

## 已有回收站更新 / Existing Trash update

回收站更新已通过 macOS Release 和 iPhone arm64 Release 构建，以及 12 项纯合并、4 项回收站与 22 项同步控制器离线检查。测试覆盖旧 v1 文档读取、v2 软删除和恢复、项目子记录保留、独立删除记录不随项目恢复、30 天到期边界及过期清理后陈旧快照不复活记录。

The Trash update passed macOS Release and iPhone arm64 Release builds, plus 12 offline merge checks, 4 Trash checks, and 22 sync-controller checks. Coverage includes reading legacy v1 documents, v2 soft deletion and restoration, retaining project children, keeping separately deleted entries trashed after project restoration, the 30-day expiry boundary, and preventing stale snapshots from resurrecting expired items.

本次已使用 Mac 与 iPhone 的现有数据库副本验证迁移，升级前后全部导出字段、UUID、关联和引用快照一致。Mac 隔离演示数据实测了单条记录与整个项目的移入回收站、恢复，以及恢复项目后独立删除的记录仍留在回收站。Store API 回归已验证同样的恢复规则、重复删除不重置期限及精确到期清理；引用保存原文保持不变。未实际等待 30 天，也未验证 iOS 在后台准点清理。应用关闭时，到期清理在下次启动或前台运行时补做。

Migration was tested on copies of the existing Mac and iPhone databases; every exported field, UUID, relationship, and reference snapshot matched before and after. Isolated demo data on Mac verified moving individual entries and whole projects to Trash and restoring them, including retaining independently deleted entries in Trash after project restoration. Store API regression checks verified the same rules, repeated deletion without resetting retention, and cleanup at the exact expiry boundary, with stored reference JSON unchanged. The checks did not wait 30 real days or validate exact-time iOS background cleanup. When the app is closed, overdue cleanup runs on the next launch or foreground session.

同步写出格式为 v2，仍使用 `TimelineSync-v1` 目录。新版可读 v1；旧版会拒绝 v2，因此需要 Mac / iPhone 一起更新。离线兼容测试不代表混用旧版客户端可安全继续同步。

Sync writes use format v2 while retaining the `TimelineSync-v1` directory. New clients read v1; older clients reject v2, so update Mac and iPhone together. Offline compatibility checks do not establish that mixed old and new clients can continue syncing safely.
